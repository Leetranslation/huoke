# 外贸获客产品调研报告

> 调研对象：麦穗获客、贸小七、海关数据方法论（底层逻辑）
> 目的：搞清「为什么我们的效果差（全是同行、评分低）」，以及该怎么改
> 调研时间：2026-10-26

---

## 一句话结论

> **他们看「谁在买」（海关提单），我们看「谁在网上」（网页搜索）。**
> 网页搜索只能证明「这家公司存在」，海关数据才能证明「这家公司在买」。
> 数据源选错了层级，后面的 AI 再强也救不回来。

---

## 一、他们到底是怎么做的

### 1. 数据源：13 个渠道，核心是「海关数据」

贸小七接入 13 种数据源：

| 数据源 | 能提供什么 | 买家判断力 |
|---|---|---|
| **海关数据（提单/报关单）** | 谁进口了什么、从谁买、买多少、多久买一次 | ⭐⭐⭐⭐⭐ **核心** |
| 展会采购商名录（广交会 2012 至今） | 30 万家真实采购商 | ⭐⭐⭐⭐ |
| 全球品牌商（WIPO 商标库） | 6500 万商标归属企业 | ⭐⭐⭐ |
| Google / Yandex / 本土引擎 | 公司存在、官网信息 | ⭐⭐ |
| LBS 地图（Google/Yandex Maps） | 本地商家（名称/电话/地址） | ⭐⭐ |
| LinkedIn（8 亿用户） | 按职位找人（KP） | ⭐⭐⭐ |
| Facebook / Instagram / WhatsApp / TikTok | 社媒账号 | ⭐ |

**关键**：网页搜索（Google）只是其中**最弱的一环**，主要用来"补公司信息"，不是用来"发现买家"的。

### 2. 买家识别：提单里的「角色区分」

这是海关数据的核心方法论。一份美国提单有 4 个角色：

| 角色 | 含义 | 是不是目标客户 |
|---|---|---|
| Importer（进口商） | 名义进口方，多为贸易公司/代理 | ❌ 可能是中间商 |
| **Consignee（收货人）** | 货物实际接收方 | ✅ **真实买家** |
| Notify Party（通知人） | 到货通知方 | ❌ 通常是清关行 |
| **Ultimate Consignee（最终收货人）** | 货物最终使用者 | ✅ **终端用户** |

> **行业共识**：优先开发 Consignee 和 Ultimate Consignee，跳过 Importer（中间商）。

### 3. 筛选：用「真实采购行为」卡门槛

不是"公司看起来像买家"，而是"公司确实在买"：

- **近 12 个月进口次数 ≥ 3 次**（稳定需求，排除试单散户）
- **最近 6-12 个月有进口记录**（活跃，排除已流失）
- **单笔金额 > 5 万美元**（有采购实力）

### 4. 评分：基于交易数据的加权模型

MIT 供应链实验室（2024）给出的买方价值评分权重：

| 维度 | 权重 | 说明 |
|---|---|---|
| HS Code 匹配度 | 28% | 技术兼容性 |
| 历史交易成长率 | 25% | 连续 3 年进口增长 >15% |
| 同业供应商重叠率 | 20% | 与你的同行重叠 = 有采购习惯 |
| 清关速度 | 17% | <48 小时 = 财务能力强 |
| 地理邻近指数 | 10% | 物流效率 |

**对比我们的评分**：产品应用 30% / 行业 20% / 买家类型 15% / 目标市场 10% / 采购能力 10% / 需求信号 15% —— **全是"主观推断"，没有一条来自真实交易**。

### 5. 「先懂你，再去找客户」（麦穗 & 贸小七都在做）

贸小七 AI 的原话：

> 当前主流工具的逻辑是「搜索 + 触达」，靠关键字字符匹配，**能找到但难大规模高度匹配**。
> 贸小七 AI 先构建「数字大脑」：分析企业官网、产品线、行业定位 → 生成企业画像 + **理想客户画像（ICP）**，再用 RAG 喂业务经验。
> **一家做 LED 灯的和一家做工业阀门的，在系统里是两套完全不同的模型。**

麦穗也一样：企业 DNA → 采购商画像 → 多源线索 → AI 背调 → 关键人识别。

### 6. 另辟蹊径：开发「同行的客户」

贸小七明确宣传：**"批量开发同行的采购商"**。

逻辑：导入同行公司名 → 系统采集同行的客户（从海关数据看谁在买同行的货）→ 定向开发。
优势：对方**已有明确采购需求**，转化率远高于盲发。

## 二、我们 vs 他们：差距对照

| 维度 | 他们 | 我们 | 差距 |
|---|---|---|---|
| **数据源** | 海关提单（谁在买）+ 展会名录 + 商标库 | DeepSeek 网页搜索 | **根本性差距**：网页只证明"存在" |
| **买家判定** | 提单 Consignee（实际收货人） | LLM 猜身份（看官网是否自称工厂） | 我们是"猜"，他们是"证" |
| **筛选门槛** | 进口频次 ≥3 次、近 6-12 月活跃 | 无（搜到什么算什么） | 我们没有"活跃度"概念 |
| **评分依据** | 交易频次/金额/成长率/HS 匹配 | 业务相似度（主观） | 我们的分是"感觉"，他们是"数据" |
| **客户画像** | 企业 DNA + ICP（理想客户画像） | 有企业 DNA（方向对） | 这一步我们**做对了** |
| **关键人** | 海关数据自带 KP 联系方式 | Search 搜邮箱 | 覆盖率差距大 |

## 三、为什么我们效果差（根因）

### 根因 1：数据源选错了层级（最致命）

```
网页搜索 = 找「哪些公司存在」        → 结果天然混杂（同行、文章、平台页）
海关数据 = 找「哪些公司在采购」      → 结果天然是买家
```

**网页上最活跃的，恰恰是同行**——因为他们要靠 SEO 卖货。买家不需要在网上宣传"我在买什么"。

这就是为什么我们搜"phone case brand"还是搜到手机壳厂：**同行在网上拼命营销，买家在网上低调采购**。

### 根因 2：评分逻辑是"像不像"，不是"买不买"

我们的 6 维度（产品应用/行业/买家类型/市场/采购能力/需求信号）全部来自**看过官网后的主观推断**。没有任何一条是"它确实在采购"的硬证据。

同行在"产品应用"维度天然满分（因为它也做这个产品），所以森廷能拿 82 分。

### 根因 3：身份判断靠"猜"（LLM 判断官网是否自称工厂）

- 准确率约 80-90%（官网信息不全就误判）
- 而且判断依据是"文案"，不是"事实"

海关数据是"事实"：它进口了 3 次，这是无法作假的。

## 四、改进路线（按成本分层）

### 方案 A：免费 —— 把网页搜索这条路做到极致（能到 60-70 分）

1. **数据源侧**：只保留"买家特征明显"的渠道（展会名录、B2B 平台采购需求页、LinkedIn 按职位筛）
2. **筛选侧**：加"活跃度"代理指标（官网是否有采购/询价页、是否在招采购、是否参加展会）
3. **评分侧**：区分「同行信号」（负分）和「采购信号」（正分）
4. **现实预期**：同行率能压到 10-20%，但**永远无法保证对方真在采购**

### 方案 B：付费 —— 接海关数据（能到 85-95 分）

1. 接一家海关数据 API（国内：贸小七/特易/顶易；国际：ImportGenius/Panjiva/ImportYeti）
2. 按 HS Code 查进口商 → 拿 Consignee → 过滤"近 12 月 ≥3 次"
3. 用真实交易数据打分（频次/金额/成长率）
4. **这是行业正路，但成本高**（国内海关数据年费通常 1-5 万）

### 方案 C：折中 —— 用免费海关数据验证（推荐先做）

- **ImportYeti**（美国进口数据，免费可查）
- **UN Comtrade**（国家级贸易统计，免费）
- 用免费数据做一次"买家验证"：把网页搜索到的公司，拿去查它有没有进口记录
- 有记录 = 真买家；无记录 = 存疑

---

## 五、结论：我们这个项目该怎么定位

**如果继续做作品集项目**：
- 承认边界：**网页搜索方案的天花板是"大概率是买家"，不是"确定是买家"**
- 把「同行剔除」做到位（已在做，同行率能压到 10-20%）
- **加分项**：在报告/面试里讲清楚"为什么网页搜索不够，海关数据才是正解"——这比吹"精准获客"更能体现你懂业务

**如果要做成真产品**：
- 必须接海关数据（这是行业门槛，绕不过去）

---

## 附：可直接借鉴的 3 个具体做法

1. **提单角色区分**：如果有人给了海关数据，优先 Consignee/Ultimate Consignee，跳过 Importer
2. **「开发同行的客户」**：这个思路免费可用——搜"同行的官网/客户案例"，反推它的客户
3. **活跃度门槛**：宁可少而准——只开发"近半年有采购信号"的公司（哪怕只有 5 家），也别要 50 家不确定的
